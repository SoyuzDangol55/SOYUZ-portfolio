About Me


Hi, I’m Soyuz Dangol, a passionate and curious BCA student currently exploring the world of web development and programming. I enjoy turning ideas into real-world projects using HTML, CSS, and JavaScript.

I started my journey with basic programming concepts and gradually moved into building interactive web applications like weather apps, UI designs, and small frontend projects. Apart from coding, I am also interested in improving my communication skills and learning how professional developers build scalable and clean systems.

My goal is to become a skilled full-stack developer and work on real-world impactful projects in the future.
